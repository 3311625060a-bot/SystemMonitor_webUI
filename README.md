# 系统监控 (System Monitor)

实时系统性能监控工具，支持 Windows 系统。

## 功能特性

- **系统配置展示**：CPU、内存、显卡、操作系统、主板信息
- **实时资源监控**：CPU 占用、内存占用、GPU 占用、显存占用
- **历史趋势图表**：可切换 60 秒 / 5 分钟 / 15 分钟 / 1 小时时间档位（选择自动保存）；内存中保留最近 1 小时数据，长档位按桶抽样，曲线刷新开销与档位无关；本机不存在的数据自动从图例中隐藏
- **I/O 吞吐量**：网络速度、磁盘读写速度（MB/s）
- **电源状态**：电池电量、充电状态
- **明暗主题**：默认跟随系统明暗设置（系统切换时自动同步）；顶栏一键切换，手动选择后会记住，下次打开沿用而不恢复默认
- **中英文切换**：默认跟随系统语言（中文系统显示中文，否则英文）；顶栏一键切换中文 / English，手动选择后同样会记住
- **多显卡支持**：识别独显 / 核显，双显卡时可在显卡详情右上角切换；单显卡机器自动隐藏切换按钮
- **后台运行 + 现代托盘面板**：启动脚本隐藏控制台启动服务；单击托盘图标弹出高 DPI 自适应面板，可查看实时占用、打开页面、结束后台进程，明暗配色跟随系统
- **开机自动启动**：托盘面板内置开关，登录 Windows 后自动在后台运行（不弹浏览器）
- **Windows 安装包**：提供轻量安装程序，一键安装、自动创建快捷方式、支持覆盖升级与干净卸载，内置便携版 Node.js，无需预装环境
- **跨设备访问**：IPv4 / IPv6 双栈监听，支持局域网内其他设备访问；具备公网 IPv6 时也可直接访问

## 快速开始

### 方法一：双击启动（推荐）

1. 双击 `启动系统监控.bat`
2. 脚本会自动检查 Node.js：缺失或版本低于 v18 时，从国内镜像下载便携版并部署到 `runtime\` 目录
3. 服务以隐藏进程在后台启动，浏览器自动打开 `http://localhost:3000`
4. 启动窗口显示访问地址后会在约 4 秒后自动关闭，**关闭窗口不会停止服务**
5. 单击任务栏托盘图标可弹出监控面板，查看实时占用、打开监控页面或结束后台进程

再次双击脚本时，如果服务已在运行，不会重复启动，只会直接打开页面。

### 方法二：安装包（正式使用推荐）

双击 `dist\SystemMonitor-Setup-1.2.2.exe` 安装（详见下文“Windows 安装包”一节）。

### 方法三：命令行启动

```bash
node server.js
```

然后访问 http://localhost:3000

## Windows 安装包

`dist\SystemMonitor-Setup-1.2.2.exe` 是轻量安装程序（约 22MB，Inno Setup 打包）：

- **每用户安装，无需管理员权限**：默认安装到 `%LOCALAPPDATA%\Programs\SystemMonitor`
- **自带 Node.js**：内置便携版 Node.js v22，目标电脑无需预装任何环境，也无需联网
- **快捷方式**：开始菜单“系统监控”，桌面快捷方式可选（安装时勾选，默认勾选）
- **署名与开源信息**：安装向导第一页展示 MIT 许可证全文，欢迎页底部显示发行商、项目主页与协议；安装包右键“属性”中的公司/版权、Windows“已安装的应用”中的发行商与反馈链接均指向作者；安装目录附带 `LICENSE`（MIT）；网页底部同样展示署名、许可证与 GitHub 入口
- **开机启动**：托盘面板中的“开机自动启动”开关，开启后写入当前用户注册表 `Run` 项，登录后以 `--silent` 参数在后台启动，不会自动弹出浏览器
- **升级**：直接运行新版本安装包即可覆盖升级，安装前会自动停止正在运行的旧版本，用户数据（无）与开机启动设置保留
- **卸载**：通过“设置 → 应用 → 已安装的应用”或开始菜单卸载；卸载时会停止后台进程、删除快捷方式、清理开机启动项
- **静默安装/卸载**：追加 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-` 参数可用于脚本批量部署

安装后启动方式：双击桌面或开始菜单的“系统监控”。启动器 `SystemMonitor.exe` 无窗口运行，检测服务状态、在后台拉起 Node 服务与托盘图标，不弹出黑色控制台；如果服务已在运行，仅直接打开监控页面。

首次启动后建议在托盘面板中按需打开“开机自动启动”。

> 说明：当前“更新”指下载新版本安装包后覆盖安装。在线自动更新需要额外的更新服务器与代码签名证书，暂未内置。

## 系统要求

- **操作系统**：Windows 10/11（64 位 / ARM64）
- **Node.js**：安装版内置便携版 Node.js，无需安装任何环境；源码 / 便携方式下启动脚本会自动部署（要求 v18+）
- **显卡驱动**：NVIDIA 显卡需要安装 nvidia-smi（通常随驱动安装）
- **网络**：安装版完全离线可用；仅源码 / 便携方式首次自动部署 Node.js 时需要联网（图表库已内置）

## 局域网访问

1. 首次启动时，启动窗口会短暂显示局域网 IPv4 地址（关闭后不影响服务）
2. 确保 Windows 防火墙允许 3000 端口（首次访问时会提示）
3. 同一局域网下的其他设备访问 IPv4：`http://<IPv4>:3000`
4. 同一局域网下的其他设备访问 IPv6：`http://[<IPv6>]:3000`

服务默认双栈监听，IPv4 与 IPv6 使用同一端口。IPv6 地址可用 `ipconfig` 查看，写入 URL 时必须带方括号。系统未启用 IPv6 时，服务会自动回退为仅 IPv4 监听。

## 托盘面板

服务运行时，任务栏通知区域会出现“系统监控”托盘图标：

- **单击图标**：弹出圆角监控面板，以卡片形式显示 CPU、内存、显卡、显存、网络、电源的实时数据；面板打开期间每 2 秒刷新一次，关闭后不产生额外开销
- **打开监控页面**：点击面板底部的“打开监控页面”，或双击托盘图标
- **开机自动启动**：点击“开机自动启动”开关即可开启/关闭，实时生效；开启后登录 Windows 时自动后台运行（不打开浏览器）。若从源码或便携方式运行，开关指向同目录下的 `SystemMonitor.exe`；找不到启动器时会提示无法设置
- **结束后台进程**：点击“结束后台进程”，停止 Node 服务并退出托盘
- **自动收起**：点击面板外部或按 `Esc` 即可收起；服务进程退出后托盘图标自动消失
- **外观自适应**：面板明暗配色跟随 Windows 系统主题，按显示器 DPI 缩放（支持 100%–200% 及多显示器），文字与图标保持清晰；任务栏图标同样按系统 DPI 生成，不会模糊
- 同一时间只会存在一个托盘图标

如需禁用托盘（例如在无桌面环境运行），设置环境变量 `MONITOR_NO_TRAY=1` 后再启动服务。

## 公网访问

如果运营商已分配公网 IPv6（地址通常以 `2` 或 `3` 开头），且光猫 / 路由器允许入站 IPv6，可在外网直接访问 `http://[<公网IPv6>]:3000`，无需端口映射；Windows 防火墙仍需放行 3000 端口。公网 IPv6 一般会随重新拨号变化，建议配合动态域名使用。

其他穿透方案：

- **ngrok**：`ngrok http 3000`
- **frp**：配置内网穿透
- **Cloudflare Tunnel**：使用 cloudflared

> 注意：页面没有登录鉴权，能连上端口的人都可以看到硬件信息和实时占用。直接暴露到公网前，请务必使用带认证的反向代理或隧道。

## 技术栈

- **后端**：Node.js（原生 http 模块 + PowerShell）
- **前端**：原生 HTML/CSS/JavaScript + Chart.js（本地文件，无需联网）
- **字体**：HarmonyOS Sans SC（可选 CDN，加载失败时自动回退系统字体）
- **零依赖**：无需 npm install，无第三方后端依赖

## 显卡识别

Windows 没有直接提供“独显 / 核显”标签，程序采用多信号交叉判断：

1. 用 `nvidia-smi` 的显存用量匹配 Windows GPU 性能计数器里的适配器，确认 NVIDIA 独显
2. 核显特征：专用显存很小、共享显存明显更大（使用系统内存）
3. 非 NVIDIA 独显：专用显存较大，且结合 `Win32_VideoController` 型号名称判断
4. 单显卡机器：系统名称能确定是核显或独显时给出准确标签；证据不足时显示“显卡”
5. 双显卡机器才会出现独显 / 核显切换按钮，单显卡机器不会显示
6. 无法确定时一律退回 `GPU 0` / `GPU 1` 中性标签，绝不会把核显标成独显
7. 历史图表只显示本机真实存在的数据：没有第二块卡时不显示第二条 GPU 曲线，没有显存信息时不显示显存曲线


## 性能设计

采集层刻意避免高频启动子进程（每次 `powershell.exe` 冷启动约 150~300ms CPU，旧实现每秒启动 7~8 个，会把 CPU 打满）：

- **CPU / 内存**：直接用 Node 原生 `os` 接口做差分采样，零子进程
- **网络 / 磁盘吞吐 / GPU / 温度 / 电池**：一个常驻 PowerShell 进程每 2 秒采集一次，其他高频项目（温度、电池）降频到 30 秒
- **核显 / 第二块 GPU**：单独一个后台采样进程，每 3 秒采集一次；只在页面轮询期间运行，页面关闭约 20 秒后自动退出，不占用空闲时的 CPU
- **接口**：`/api/metrics` 只返回内存中的缓存快照，响应约 1~2ms
- **前端**：请求不重叠、标签页隐藏时自动停止轮询、DOM 无变化时跳过重绘

实测（16 核笔记本）：旧实现单次请求 3.4 秒、CPU 100%、35 个 PowerShell 进程；现实现单次请求 1.5ms、常驻 1 个 PowerShell 进程，GPU 采样期间约多 1 个进程。

## 常见问题

### Q: 提示找不到 Node.js
A: 安装版内置便携版 Node.js，不会出现该提示。只有从源码 / 便携方式运行（`启动系统监控.bat`）时才涉及依赖部署：脚本会自动从国内镜像（npmmirror / 腾讯云 / 华为云）下载兼容的 Node.js 便携版并部署到 `runtime\`，无需手动安装。仅当自动下载失败时，才需要手动下载后解压到 `runtime\node\`：

- https://npmmirror.com/mirrors/node/
- https://mirrors.cloud.tencent.com/nodejs-release/

### Q: 显卡类型显示成 GPU 1 / GPU 2
A: 这是保护性回退。程序只在证据充分时才标注“独立显卡 / 核显”，无法确定时使用中性编号，避免误标。若某台机器长期如此，可反馈该机器的显卡型号。

### Q: CPU 温度显示 "--"
A: Windows 标准 WMI 接口通常不提供 CPU 温度，这是系统限制

### Q: 显卡占用率显示 0%
A: GPU 空闲时占用率为 0 是正常的，运行图形应用时会显示真实占用

### Q: 局域网无法访问
A: 检查 Windows 防火墙设置，确保允许 3000 端口入站连接

### Q: IPv6 地址无法访问
A: 依次确认：Windows 已启用 IPv6；防火墙允许 3000 端口的 IPv6 入站连接；路由器 / 光猫未拦截入站 IPv6。URL 必须写成 `http://[IPv6]:3000`，方括号不能省略；`fe80::` 开头的链路本地地址需要指定网卡，不建议使用。从外网直接访问还需要运营商分配公网 IPv6，且地址可能随拨号变化，建议配合 DDNS。

### Q: 启动后浏览器提示「无法访问此网站 / ERR_CONNECTION_REFUSED」
A: 说明服务没起来。启动脚本现在会轮询等待端口就绪后再打开浏览器，失败时直接把 `server.log` 打印到窗口里。按顺序排查：

1. 如果用 `启动系统监控.bat` 启动：窗口里是否出现 `[OK] Node.js: ...`，没有则说明依赖部署失败（脚本会先搜索 PATH、Program Files、WinGet、Scoop、LM Studio 自带的 node.exe，都没有时自动下载便携版）；如果用安装版启动，安装包已内置 Node.js，不会出现依赖问题，可直接看第 3 步的 `server.log`
2. 端口是否被占用：`netstat -ano | findstr :3000`，如有残留进程，可单击托盘图标选择“结束后台进程”
3. 检查窗口末尾的 `server.log` 内容，里面是服务的真实报错
4. 启动窗口自动关闭属于正常现象，服务已转入后台，关闭窗口不会停止服务；彻底退出请使用托盘面板的“结束后台进程”

### Q: 启动窗口一闪而过，服务还在运行吗？
A: 在。脚本用隐藏窗口启动 Node 服务，控制台只负责显示访问地址，约 4 秒后自动关闭。之后可通过托盘图标确认服务状态，或直接访问 http://localhost:3000。

### Q: 如何彻底结束后台服务？
A: 单击托盘图标 → “结束后台进程”，服务和托盘会一起退出。如果托盘图标异常消失，可在任务管理器中结束命令行包含 `server.js` 的 `node.exe`。

### Q: 托盘图标没有出现 / 消失了？
A: 托盘仅支持 Windows，且服务进程必须处于运行状态。可先访问页面确认服务正常，再检查任务栏通知区域是否折叠了图标；服务退出后托盘会自动消失，重新双击 `启动系统监控.bat` 即可恢复。

### Q: 如何切换界面语言？
A: 点击顶栏 `EN` / `中` 按钮切换中文和英文。默认跟随系统语言（中文系统显示中文，其他显示英文），手动切换后会记住选择；明暗主题同理，默认跟随系统、手动切换后记住。

### Q: 如何设置开机自动启动？
A: 单击托盘图标，在面板底部打开“开机自动启动”开关即可。开启后写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `SystemMonitor` 值，登录 Windows 后自动在后台运行，不弹出浏览器；关闭开关会删除该值。

### Q: 安装版如何更新？
A: 下载新版本安装包（`SystemMonitor-Setup-<版本>.exe`），直接运行覆盖安装即可。安装程序会先调用旧版本的 `SystemMonitor.exe --stop` 停止后台服务，再替换文件，快捷方式与开机启动设置保留。安装完成后重新启动程序即可。

### Q: 安装包需要联网或预装 Node.js 吗？
A: 都不需要。安装包内置便携版 Node.js v22，安装后完全离线可用。

### Q: 如何静默安装或批量部署？
A: 使用 `SystemMonitor-Setup-1.2.2.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-`，静默模式下不显示安装向导；卸载同理对 `unins000.exe` 使用相同参数。

> 上文“自动部署 Node.js”仅针对源码 / 便携方式（`启动系统监控.bat`）：首次约下载 33MB（仅一次），优先使用国内镜像；部署完成后 `runtime\` 目录可随项目一起复制到其他电脑，无需再联网。安装版安装包已内置运行时，无需任何下载。
